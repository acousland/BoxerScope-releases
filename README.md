# BoxerScope for Mac

Native diagnostics for BMW R1200GS K25 motorcycles through a UniCarScan UCSI-2100 adapter.

**[Download the latest installer](https://github.com/acousland/BoxerScope-releases/releases/latest)** · **[About BoxerScope](https://acousland.github.io/boxerscope/)**

Requires macOS 14 or later. The Mac installer supports Apple silicon and Intel, is Developer ID signed, and is notarised by Apple.

## Install

1. Download and open the disk image from Releases.
2. Drag BoxerScope into Applications.
3. Pair the UniCarScan UCSI-2100 in macOS System Settings before connecting.

Use a supported K25 motorcycle with its ignition on. Scan results and available live data come from the connected adapter and vehicle. Write and service operations remain locked until their live request/response sequences are validated.

This repository hosts public Mac installers, checksums, and release notes. The source repository remains private. iPhone and iPad apps are not distributed through these releases.
